# StudioSpace — Creative Studio Marketplace

**Live Website:** https://studio-space-nine.vercel.app/

StudioSpace is a peer-to-peer marketplace where creators can discover and book creative spaces such as photography studios, film stages, podcast rooms, music suites, and art workshops.

## ✨ Key Features

- **Explore Creative Studios:** Browse available studios with category, location, hourly rate, and ratings.
- **Dynamic Homepage:** Discover featured studios, browse categories, and learn how the booking process works.
- **User Authentication:** Register and log in using email and password, with Google sign-in when configured.
- **Studio Management:** Hosts can add, update, view, and manage their studio listings.
- **Booking System:** Users can request studio bookings and track their booking status.
- **Booking Management:** Hosts can manage booking requests, while customers can view and cancel eligible bookings.
- **Reviews and Ratings:** Users can share feedback on eligible bookings.
- **Responsive Design:** Optimized layouts for mobile, tablet, and desktop devices.
- **Theme Customization:** Switch between light and dark themes.
- **User Feedback:** Toast notifications, loading states, and helpful empty states provide a smoother experience.

## 🚀 Getting Started

### Prerequisites

- Node.js (LTS recommended)
- npm
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/smerfan0009-sys/studio-space.git
```

### 2. Navigate to the Project

```bash
cd studio-space
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Run the Development Server

```bash
npm run dev
```

Open [http://localhost:3000] in your browser.

## 🔐 Security

- Authentication is handled through the configured authentication service.
- Protected operations are validated by the backend.
- Authentication cookies are configured to support secure session handling.
- Private credentials and environment files must remain outside version control.
